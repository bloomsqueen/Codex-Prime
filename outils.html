15 outils d'IA, comparés

Pour créer un site ou une application sans écrire le code soi-même.

Analyse du 12 octobre 2026. Je n'ai testé aucun de ces outils.

Créer une application vite

Ces outils fonctionnent à partir d'une description écrite.

Outils pour créer une application à partir d'une description
Outil À quoi il sert
Lovable Crée une application complète à partir d'une description, avec une base de données (Supabase).
Bolt.new Crée une application à partir d'une description en langage naturel. Édité par StackBlitz.
Replit Construit et améliore une application avec son assistant, Replit Agent.
v0 Génère des écrans et des composants d'interface. Édité par Vercel.

Être aidé pour écrire du code

Un terminal est une fenêtre où l'on tape des commandes. Un éditeur est un programme pour écrire du code. Les outils ci-dessous demandent plus de pratique.

Assistants d'aide à l'écriture de code
Outil À quoi il sert
Claude Code Assistant qui travaille dans un terminal (fenêtre de commandes) et sur un projet entier.
Cursor Éditeur de code avec un assistant pour écrire, corriger et relire.
GitHub Copilot Aide à écrire du code dans GitHub et dans les éditeurs.
Gemini CLI Assistant en terminal, ouvert (code public). Pas d'abonnement grand public d'après le dépôt. Accès par clé d'API (une clé d'accès personnelle) ou offre entreprise.
OpenAI Codex CLI Assistant d'OpenAI qui s'exécute dans le terminal de l'ordinateur.

Soigner l'apparence

Ce sont des ressources à donner à l'IA, pas des IA. Descriptions non vérifiées : je n'ai pas ouvert ces sites, et les chiffres sont des annonces.

Ressources de design à fournir à l'IA
Outil À quoi il sert
Scrollslide Prompts et code prêts à copier dans Claude, Cursor ou Lovable, pour des sites animés. Annonce : « 600+ prompts ».
21st.dev Catalogue de composants (boutons, formulaires…) que l'IA peut utiliser via MCP.
shadcn/ui Composants d'interface réutilisables. Décrit comme la référence pour une interface propre.
DESIGN.md Styles visuels écrits en texte, que l'IA peut lire pour respecter une charte.
Refero Styles Annonce : « 2 000+ » styles de vrais produits, avec leurs polices.
Component Gallery Annonce : « 2 600+ » exemples d'un même élément d'interface dans de grands systèmes de design.

Sources et fiabilité

Les outils viennent de deux sources, qui n'ont pas le même niveau de preuve.

Dépôt GitHub awesome-vibecoding : fiabilité moyenne à bonne

Source de Lovable, Bolt.new, Replit, v0, Claude Code, Cursor, GitHub Copilot, Gemini CLI et OpenAI Codex CLI. Scap-Mehdi/awesome-vibecoding, fichier README.fr.md, relu le 12 octobre 2026. Ces 9 outils portent tous la date de vérification du 18 septembre 2026.

  • Pour : une date par entrée, un accès et une licence indiqués, des fiches de preuves pour la plupart des entrées.
  • Contre : le dépôt est mis à jour par un agent automatique. La mention « vérifié » est en partie automatisée. Les prix sont souvent non examinés (« à vérifier »).
  • Non vérifié par moi : je n'ai ouvert ni les fiches de preuves ni les sites des outils.

Post sur X : fiabilité faible

Source de Scrollslide, 21st.dev, shadcn/ui, DESIGN.md, Refero Styles et Component Gallery. Capture d'écran d'un post d'un compte au prénom Himanshu, qui se présente comme fondateur de Scrollslide.

  • Contre : la première ressource de la liste est le produit de l'auteur. Aucune date, aucun prix, aucune preuve par entrée. Les chiffres (« 600+ », « 2 000+ ») sont des annonces.
  • Non vérifié : la capture est en basse résolution. Le nom de famille, l'identifiant, l'année et les compteurs sont illisibles. Je n'ai pas ouvert les sites cités : les descriptions viennent uniquement du post.

Ce que cette page ne dit pas

Aucun classement : je n'ai pas comparé la qualité des résultats. Les prix changent souvent : vérifiez-les sur le site de chaque outil avant de vous inscrire. Les catégories sont les miennes, pour faciliter la lecture.
